================================================================================
COMPONENTES (CARPETAS DEL MONOREPO)
================================================================================

1. businessdomain/incidentes
   Microservicio de gestion de incidentes. Patron Factory Method + JPA/H2.
   Eureka: INCIDENTES | API: /incidentes | Swagger: /swagger-ui.html

2. businessdomain/recursos
   Microservicio logistico (brigadas, vehiculos, equipos). JPA/H2.
   Eureka: RECURSOS | API: /recursos

3. businessdomain/zonasriesgo
   Analisis territorial y clima (Adapter FakeWeather). JPA/H2.
   Eureka: ZONASRIESGO | API: /zonas-riesgo

4. infraestructuredomain/bff
   Backend For Frontend. Facade + Circuit Breaker. Puerto 8085.
   API: GET /bff/emergencias/{id}/resumen

5. infraestructuredomain/apigateway
   API Gateway Spring Cloud. Puerto 8080. Enruta BFF y microservicios.

6. infraestructuredomain/eurekaServer
   Service Discovery. Puerto 8761.

7. frontend/sre-ui
   Paquete NPM React + Vite. Panel centro de operaciones SRE.
